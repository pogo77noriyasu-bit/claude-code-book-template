# Issueトリアージ

GitHub Issueの内容を読み、分類してください。

## 分類ルール

- bug：不具合・正常に動作しない
- enhancement：機能追加・改善要望
- documentation：説明書・仕様書の修正
- question：質問・相談

## 実行手順

1. 対象Issueのタイトルと本文を確認する
2. 内容に合ったラベルを1つ選ぶ
3. 選んだ理由を日本語で簡潔に説明する
4. 判断できない場合は「要確認」とする

## 注意事項

- Issueの内容を勝手に変更しない
- ラベルを勝手に登録・変更しない
- ソースコードを変更しない
- 分類結果を表示するだけにする
