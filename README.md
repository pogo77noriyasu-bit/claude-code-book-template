# claude-code-book-template

Claude Code を使って作ったブラウザゲームとアプリを集めたリポジトリです。ゲームはどれも HTML + バニラ JavaScript だけで作られていて、ビルドやインストールなしで遊べます。

## プロジェクトの概要

- プロジェクトごとにディレクトリを分けています(`games/` と `apps/`)。
- 各プロジェクトのディレクトリには、そのプロジェクト専用の `CLAUDE.md`(構成・設計メモ)があります。
- リポジトリ共通の開発ルールはルートの `CLAUDE.md` に書いています。
- 画面の文字とコードコメントは日本語です。

```
.
├── games/
│   ├── breakout/        ブロック崩し
│   ├── meteor-dodge/    流星よけ
│   ├── hori-pon/        ほりポン
│   ├── hoshimushi/      ほしむし艦隊
│   └── kikori-mokuta/   きこりのモク太
├── apps/
│   └── task-manager/    タスク管理アプリ
├── index.html           GitHub Pages のトップページ(一覧)
└── CLAUDE.md            共通の開発ルール
```

## ゲームの一覧と遊び方

どのゲームも、キーボードのほかマウスやタッチでも操作できます。共通の操作は次のとおりです。

- スペース / Enter / クリック / タップ: スタート・リトライ
- P: 一時停止(ほりポンは Esc も可)
- M: 効果音 ON/OFF(キャンバス下のボタンでも切り替え可)

### ブロック崩し(`games/breakout/`)

パドルでボールを打ち返し、ブロックをすべて壊すゲームです。

- 操作: ←→ / A D でパドルを動かす。マウス・タッチでも動かせる。
- 壊したブロックからアイテムが落ちることがある(パドルが広がる、ボールが遅くなる、貫通する、ボールが増える、ライフ +1)。
- 全ブロックを壊すと次のレベルへ進み、ボールが速くなる。ブロックは上の行ほど高得点。
- ハイスコアはブラウザに保存される。

### 流星よけ(`games/meteor-dodge/`)

上から降ってくる隕石をよけながら星を集める避けゲーです。

- 操作: ←→ / A D で移動、マウスはカーソルに追従、タッチはドラッグで移動。
- 星は +50 点。シールドを取ると 6 秒間無敵で隕石を壊せる。ハートでライフ +1。
- ライフは 3。被弾すると少しの間無敵になる。生存時間が長いほど高得点で、時間とともに難しくなる。
- ハイスコアはブラウザに保存される。

### ほりポン(`games/hori-pon/`)

土を掘り進み、地中の敵(怒った女子)をポンプでふくらませて破裂させるか、岩(ビール缶・ジョッキ)を落として潰す穴掘りアクションです。主人公はモヒカンパンクです。

- 操作: 矢印 / WASD で移動(進む先が土なら掘る)。スペース / Z / X / J でポンプを撃つ。刺したまま連打・長押しでふくらむ。
- 敵は掘ってつながった穴だけを通れる。敵をすべて倒すと面クリア。
- タッチ端末では十字キーとポンプボタンが表示される。

### ほしむし艦隊(`games/hoshimushi/`)

編隊を組んだ虫型の敵が宙返りしながら突撃してくる、固定画面シューティングです。

- 操作: ←→ / A D で移動、スペースで発射(押しっぱなしで連射)。タッチ・マウスは押している間、指の位置へ移動しながら連射。
- 敵の女王にさらわれた自機を撃ち落とさずに助けると、2機合体のダブルになる。
- ボーナスステージや命中率表示があり、ゲームオーバー時にはランキングの名前入力がある。

### きこりのモク太(`games/kikori-mokuta/`)

ヘビやイノシシ、落ちてくる枝、鳥のフンをよけながら、オノで木を切り倒す木こりアクションです。

- 操作: ←→ / A D で移動。スペース / Z / J / Enter でオノを振る。↓ / S で木の陰にかくれる。
- 木を 3 本倒すと面クリア。倒れる木は敵の下敷きにもできる。
- イノシシは突進の前に「!」で予告する。枝は地面の影で落ちる場所がわかる。
- タッチ端末ではキャンバス下に操作ボタンが表示される。

## アプリ

### タスク管理アプリ(`apps/task-manager/`)

タスクの追加・編集・削除・完了マークができるシンプルなアプリです(React 19 + Vite)。タスクはサーバー側の `data/tasks.json` に保存され、サーバーに届かないときはブラウザの `localStorage` だけで動きます。

## 開発環境

- ゲーム(`games/`): HTML + バニラ JavaScript(`<canvas>` 描画)。ビルド手順、パッケージマネージャ、テストはありません。効果音は Web Audio API で合成しています。
- タスク管理アプリ(`apps/task-manager/`): Node.js、React 19、Vite、JavaScript / JSX(TypeScript なし)。
- 開発コンテナ(`.devcontainer/`): Debian bookworm ベースで、Node.js と GitHub CLI が入っています。ポート 5173 を転送します。VS Code の Dev Containers などで開けます。
- ブラウザ: Canvas と Web Audio API に対応した最近のブラウザ。

## 起動方法

### ゲーム

方法 1: `games/<ゲーム名>/index.html` をブラウザで直接開く。

方法 2: リポジトリのルートを静的配信して、ブラウザで `/games/<ゲーム名>/` を開く。

```bash
# どちらか一方
npx http-server -c-1 -p 8000
python3 -m http.server 8000
```

例: `http://localhost:8000/games/breakout/`

- `http-server` はキャッシュ設定なしだと古い `main.js` がブラウザに残ることがあります。`-c-1` を付けるか、Ctrl+Shift+R で強制再読み込みしてください。
- ルートの `index.html` を開くと、すべてのプロジェクトの一覧から選べます。

### タスク管理アプリ

`apps/task-manager/` で次を実行します。

```bash
cd apps/task-manager
npm install        # 初回のみ
npm run dev        # 開発サーバー(http://localhost:5173/)
npm run build      # dist/ に本番用ビルドを出力
npm run preview    # ビルド結果の確認(タスク保存 API も動く)
```

`dist/` だけを静的配信すると保存 API がないため、タスクは各ブラウザの `localStorage` にだけ保存されます。
