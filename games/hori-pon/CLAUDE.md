# CLAUDE.md

このファイルは、ほりポンプロジェクト(`games/hori-pon/`)専用のガイドです。リポジトリ全体の共通ルールはルートの `CLAUDE.md` を参照。

## 概要

ブラウザで遊ぶ、縦長固定画面の穴掘りアクション。主人公が土を掘り進み、地中のモンスターをポンプでふくらませて破裂させるか、岩を落として潰す。素の HTML + バニラ JavaScript で `<canvas>` に描画している。ビルド手順、パッケージマネージャ、テストはない。画面の文字とコードコメントはすべて日本語。

キャラクターは、主人公 = モヒカンパンク(`drawPlayer()`)、敵 = 怒った女子(`drawEnemy()` / `drawGirlHead()`、ふくらむとほっぺをふくらませる)、岩 = ビール缶とビールジョッキ(`drawRock()`、岩の `kind` 0/1)。見た目だけの差し替えで、コード内の変数名は rock / enemy のまま。

穴掘りアクションというジャンルの仕様を参考にしたオリジナル作品。既存ゲームの名前・キャラクター・見た目・音楽・ステージは使わないこと。

## 実行方法

`index.html` をブラウザで直接開くか、リポジトリのルートを静的配信して(例: `npx http-server -c-1 -p 8000`)`/games/hori-pon/` を開く。

## 操作

- 矢印 / WASD: 移動(進む先が土なら掘る)
- スペース / Z / X / J: ポンプ(銛)を撃つ。刺したまま連打・長押し・刺し直しでふくらむ
- Enter / スペース / クリック / タップ: スタート・リトライ
- P / Esc: 一時停止、M: 音 ON/OFF(キャンバス下のボタンでも切り替え可)
- タッチ端末(`pointer: coarse`)では十字キーとポンプボタンを表示する

## 構成

- `index.html` — レイアウトとスタイル、固定サイズの `<canvas id="game" width="448" height="576">`、タッチ用ボタン。
- `main.js` — ゲーム全体。上から順に、設定、状態、保存、効果音・音楽、地形ヘルパー、面の生成、状態遷移、入力、更新(主人公 / 銛 / 敵 / 岩 / 全体)、描画、ループ。

設計上の要点:

- **マス目**: 1マス 32px、14×18 マス。0 行目と 17 行目は HUD、1 行目は地上(最初から歩ける)、2〜16 行目が地中。地層は 4 行ごとに 4 段階(`layerOf()`)。
- **地形**: `dug[y][x]`(掘られたマス)と、隣のマスとのつながり `hOpen`(右隣)/ `vOpen`(下隣)で表す。敵と銛は「つながった穴」しか通れない。掘るときは必ず `openEdge()` を使う。
- **移動**: 主人公と敵はマスの中心から中心へ動き、曲がれるのは中心だけ。座標はマス単位の小数、速度はマス/秒、`dt` は最大 0.05 秒。主人公は途中で反転できる(その区間は掘れたことになる)。
- **状態遷移**: `state` = `'title' | 'ready' | 'playing' | 'dying' | 'clear' | 'gameover' | 'paused'`。
- **敵**: `state` = `'walk' | 'ghost' | 'crushed' | 'dead' | 'escaped'`。`walk` は穴の中を BFS(`bfsNextDir()`)で主人公へ向かう(一部ランダム)。`ghostT` が切れると `ghost`(すり抜け)になり、遅い速度で土の中を主人公へまっすぐ進み、一度土に入った後で穴のマスに着くと `walk` に戻る。
- **ポンプ**: `harpoon.state` = `'extend' | 'retract' | 'attached'`。`inflate` が 4(`POP_STAGE`)で破裂。`DEFLATE_INTERVAL` 秒ごとに 1 段階しぼむ。ふくらんでいる敵には触れてもミスにならない。刺したまま移動すると外れる。
- **岩**: `state` = `'still' | 'wobble' | 'fall' | 'break'`。真下のマスが掘られると、主人公がそこで上を向いていれば落ちない(`ROCK_HOLD_GRACE` 秒の猶予あり)。一度別の向きにしたら `holdable = false` で抑えられなくなる。落下中に巻き込んだ敵をまとめて潰し、`ROCK_SCORE[潰した数]` 点。着地すると `break` になり、`ROCK_BREAK_TIME` 秒かけて泡(`FOAM_BUBBLES`)があふれ出て消える(効果音 `fizz`)。
- **スピードアップ / 撤退**: `speedupTimes()` の秒数で敵が 25% ずつ速くなる。残り 1 匹になると `escaping` になり、地上の左上 (0,1) へ逃げる。全滅か撤退完了で面クリア。
- **音楽**: 主人公が動いたステップだけ `MELODY` が進み、止まっている間は敵の足音を鳴らす(`updateMusic()`)。

## 実装ルール

- スコアは `localStorage` に保存すること。キーは `horiPon.highScore`、音設定は `horiPon.sound`(`'on'`/`'off'`)。読み書きは必ず `loadStorage()` / `saveStorage()` を通す。
- 効果音・音楽は Web Audio API で合成し、ON/OFF を切り替えられるようにすること。鳴らすときは必ず `playSound(name)` を使う。
