# CLAUDE.md

このファイルは、きこりのパンクプロジェクト(`games/kikori-mokuta/`)専用のガイドです。リポジトリ全体の共通ルールはルートの `CLAUDE.md` を参照。

## 概要

横から見た画面の木こりアクション「きこりのパンク」。赤いモヒカンのパンク木こり・モク太を左右に動かし、ヘビやイノシシ、落ちてくる枝、鳥のフンをよけながらオノで木を切り倒す。3本倒すと面クリア。素の HTML + バニラ JavaScript で `<canvas>` に描画している。ビルド手順、パッケージマネージャ、テストはない。画面の文字とコードコメントはすべて日本語。

「敵をよけながら木を切り倒す」という昔からあるアーケードゲームの遊び方を参考にしたオリジナル作品。特定の既存作品の名前・キャラクター・楽曲・見た目は使わないこと(BGM・ジングルも自作のフレーズにする)。

タイトルは旧名「きこりのモク太」から「きこりのパンク」に変えた。主人公の名前はモク太のまま。ディレクトリ名 `kikori-mokuta/` と保存キー `kikoriMokuta.*` は、リンクと保存済みのハイスコアを保つため旧名のまま残している。

## 実行方法

`index.html` をブラウザで直接開くか、リポジトリのルートを静的配信して(例: `npx http-server -c-1 -p 8000`)`/games/kikori-mokuta/` を開く。

## 操作

- ←→ / A D: 移動
- スペース / Z / J / Enter: オノを振る(スタート・リトライも兼ねる)
- ↓ / S: 立っている木に重なっているとき、木の陰にかくれる
- P: 一時停止、M: 効果音 ON/OFF(キャンバス下のボタンでも切り替え可)
- タッチ端末ではキャンバス下に ◀ / かくれる / ▶ / オノ ボタンが出る

## 構成

- `index.html` — レイアウトとスタイル、固定サイズの `<canvas id="game" width="640" height="480">`、タッチ用ボタン。
- `main.js` — ゲーム全体。上から順に、設定、状態、保存、効果音、初期化・状態遷移、入力、行動(オノ)、生成、更新、描画、ループ。

設計上の要点:

- **状態遷移**: 文字列 `state` — `'ready' | 'playing' | 'dying' | 'clear' | 'paused' | 'gameover'`。`dying`(やられ演出 2 秒)と `clear`(面クリア演出)は `stateTimer` で次へ進む。一時停止は `pausedFrom` に元の状態を覚えて戻す。
- **時間**: デルタタイム(秒)ベース。`dt` は最大 0.05 秒に制限。速度の定数は px/秒。
- **オノ**: `chop()` は届く範囲(前方 6〜52px)の敵を優先して倒し、いなければ目の前の木(`treeInFront()`)の HP を 1 減らす。木の HP は `TREE_HP`(8)。
- **木**: `state` が `'stand' → 'falling' → 'down' → 'gone'`。プレイヤーの向いている方向に倒れ、倒れる途中でその側にいる敵を下敷きにする。
- **危険物**:
  - ヘビ(ゆっくり、ときどき向きを変える)とイノシシ(端に「！」で予告してから突進)。当たるとミス。木の陰にかくれていれば当たらない。
  - 枝: 木を切ったときに確率で落ちてくる。地面に影が出て予告される。かくれていても防げない。
  - 鳥のフン: 当たると `STUN_TIME` 秒しびれて動けない。かくれていれば防げる。
- **アイテム**(`items`。`spawnItem()` / `updateItems()` / `pickUp()` / `drawItem()`):
  - 安全ピン: 木を切ると 6%、イノシシを倒すと 100%、ヘビを倒すと 20% で出る。5 本集めると残機 +1(上限 `LIFE_CAP` = 5。上限なら 1000 点)。数は HUD に表示し、面をまたいで持ち越す。
  - ビール缶: 木が倒れ始めると 35% で出る(その面の最後の木は除く)。拾うと 500 点。
  - どちらもドット絵(`drawSprite()`)。地面に落ちて 8 秒で消える。ミス・面の開始で消える。
- **難易度**: 面数 `stage` に応じて、敵の速さ・出現間隔・同時数(最大 4)、イノシシの割合、枝の落ちる確率、鳥の頻度が上がる。理不尽にならないよう、当たり判定は見た目より小さめで、危険物には必ず予告を付ける。
- **得点**: 木に 1 回入れる 10、木を倒す 500、ヘビ 100、イノシシ 200、下敷き 300、面クリア 1000×面数、ビール缶 500。

## 実装ルール

- スコアは `localStorage` に保存すること。キーは `kikoriMokuta.highScore`、効果音設定は `kikoriMokuta.sound`(`'on'`/`'off'`)。読み書きは必ず `loadStorage()` / `saveStorage()` を通す。
- 効果音は Web Audio API で合成し、ON/OFF を切り替えられるようにすること。鳴らすときは必ず `playSound(name)` を使う。
