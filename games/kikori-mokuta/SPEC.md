# きこりのパンク 仕様書

`games/kikori-mokuta/index.html` と `games/kikori-mokuta/main.js` のソースコードを解析してまとめた仕様書です。コードに実装されている内容だけを記載しています。コードから判断できない点は「要確認」と明記しています。

- 記載の数値(速度・時間・座標など)は `main.js` の値です。速度の単位は px/秒、時間の単位は秒です。
- 括弧内の `定数名` や関数名は、`main.js` 内の対応箇所を示します。

---

## 1. ゲーム概要

| 項目 | 内容 |
| --- | --- |
| タイトル | きこりのパンク(旧名: きこりのモク太。主人公の名前はモク太のまま) |
| ジャンル | 横から見た画面の木こりアクション(1人用) |
| 実装 | HTML + バニラ JavaScript。`<canvas id="game">` に描画 |
| 画面サイズ | 内部解像度 640×480。表示は画面に収まるよう縮小される(`index.html` の CSS) |
| 地面の高さ | y = 400(`GROUND`) |
| 目的 | ヘビ・イノシシ・落ちてくる枝・鳥のフンをよけながら、オノで木を切り倒す。1面に3本ある木を全部倒すと面クリア |
| 終了 | 残機(ライフ)がなくなるとゲームオーバー。最終面の設定はない(後述) |
| 保存 | ハイスコアと効果音の ON/OFF を `localStorage` に保存 |
| 効果音 | Web Audio API で合成。外部の音声ファイルは使わない |
| BGM | 実装なし(効果音とジングルのみ) |

### ファイル構成

- `index.html` — レイアウト、スタイル、`<canvas>`、タッチ用ボタン、効果音 ON/OFF ボタン
- `main.js` — ゲーム本体(設定、状態、保存、効果音、状態遷移、入力、オノの処理、生成、更新、描画、メインループ)

## 2. 操作方法

### キーボード

| 操作 | キー |
| --- | --- |
| 左へ移動 | ← / A |
| 右へ移動 | → / D |
| 木の陰にかくれる | ↓ / S(押している間) |
| オノを振る | スペース / Enter / Z / J |
| ゲーム開始・リトライ | スペース / Enter / Z / J |
| 一時停止・再開 | P(再開はスペース等の「オノ」キーでも可) |
| 効果音 ON/OFF | M |

- オノのキーは押しっぱなしにしても連打にならない(`e.repeat` を無視)。1回ずつ押す必要がある。
- ←→↓ と オノのキーは `preventDefault()` されるため、ページはスクロールしない。
- 画面下の説明文(`index.html`)には「←→ 移動 ・ スペース/Z オノ ・ ↓ 木にかくれる ・ P 一時停止」とだけ書かれている。A/D/S/J/Enter/M は説明文に載っていないが、コードでは有効。

### マウス・タッチ

- **キャンバスのクリック/タップ**: プレイ中以外(`state !== 'playing'`)のときだけ反応する。
  - 開始前・ゲームオーバー → ゲーム開始(リトライ)
  - 一時停止中 → 再開
  - **プレイ中のクリックではオノを振らない**(何も起きない)。
- **タッチ用ボタン**(キャンバスの下): ◀ / かくれる / ▶ / オノ。押している間だけ、対応するキーが押されている扱いになる。「オノ」ボタンはスペースキーと同じ処理(開始・リトライ・再開・オノ)。
- タッチ用ボタンは `@media (hover: hover) and (pointer: fine)` に当てはまる環境(マウス主体の PC など)では CSS で非表示になる。

### その他

- **効果音ボタン**: キャンバス下の「音: ON / 音: OFF」ボタンでも切り替えられる。クリック後にフォーカスを外す(スペースキーでボタンが反応しないようにするため)。
- **自動一時停止**: ブラウザのタブが非表示になると、`playing` / `dying` / `clear` のいずれかなら自動で一時停止する。そのとき移動・かくれるのキー状態もすべて解除される。
- **一時停止できる状態**: `playing` / `dying` / `clear` のみ。開始前とゲームオーバーでは P を押しても何も起きない。

## 3. ゲームルール

### 3.1 状態

`state` は次の6つのいずれか。

| 状態 | 内容 |
| --- | --- |
| `ready` | 開始前のタイトル画面 |
| `playing` | プレイ中 |
| `dying` | やられ演出中(2秒) |
| `clear` | 面クリア演出中(2.6秒) |
| `paused` | 一時停止中(再開すると元の状態に戻る) |
| `gameover` | ゲームオーバー |

### 3.2 プレイヤー(モク太)

| 項目 | 値 |
| --- | --- |
| 開始位置 | x = 50、右向き(面の開始ごとに戻る) |
| 移動速度 | 170 px/秒(`PLAYER_SPEED`) |
| 移動範囲 | x = 16 〜 624 |
| 当たり判定 | 左右方向だけで判定。半幅 10 px(`PLAYER_HALF`) |
| オノの間隔 | 0.24 秒(`CHOP_COOLDOWN`) |
| オノを振る時間 | 0.16 秒(`SWING_TIME`) |
| 復活・面開始直後の無敵 | 2 秒(`RESPAWN_INVINCIBLE`) |

- オノを振っている間(0.16 秒)は移動できず、向きも変えられない。
- 向きは最後に動いた方向(右 = 1、左 = -1)。オノはこの向きに振る。
- 上下方向の移動やジャンプはない。

### 3.3 オノ(`chop()`)

次のいずれかのときは、オノを振れない(何も起きない)。

- オノの間隔が空いていない
- 鳥のフンでしびれている
- 木の陰にかくれている

オノを振ると、次の順で判定する。

1. **敵への攻撃**: 向いている方向の前方 6 〜 52 px の範囲に敵がいれば、その範囲に重なっている敵をすべて倒す(ヘビもイノシシも1振りで倒せる)。
   - 出現予告中(「！」表示中)の敵と、すでに倒した敵は対象外。
   - 敵を倒した場合は、同じ1振りで木には当たらない。
2. **木への攻撃**: 敵がいなければ、目の前の立っている木を切る。
   - 「目の前」は、向いている方向に 8 px より遠く 42 px より近い位置(`treeInFront()`)にある、立っている木。
   - 当たると木の体力(HP)が 1 減る。木の HP は 8(`TREE_HP`)なので、同じ木に8回当てると倒れる。
   - 倒れた(HP 0)のとき、木はプレイヤーが向いている方向(= プレイヤーから見て木の向こう側)へ倒れる。
3. **空振り**: 敵も木も範囲にない場合は空振りの効果音だけが鳴る。

### 3.4 木の陰にかくれる

- ↓(または S、タッチの「かくれる」)を押している間、立っている木の中心から 22 px 未満の位置にいると「かくれる」状態になる。
- かくれている間は、移動もオノもできない。
- かくれている間の効果:

| 危険物 | かくれると |
| --- | --- |
| ヘビ・イノシシ | 当たらない |
| 鳥のフン | 防げる |
| 落ちてくる枝 | **防げない**(`updateBranches` はかくれ状態を見ていない) |

- 倒れた木(`down`)や消えた木(`gone`)の位置ではかくれられない。立っている木(`stand`)だけが対象。
- 描画上は、かくれている間のモク太が半透明(透明度 0.45)になり、木より奥に描かれる。

### 3.5 ミス(やられ)になる条件

次の場合にミスになり、`dying` 状態に入る。ミスになるのは `playing` のときだけ。

- **ヘビ・イノシシに当たる**(かくれていない、かつ無敵でないとき)
- **落ちてきた枝に当たる**(無敵でないとき。かくれていても当たる)

鳥のフンに当たってもミスにはならず、しびれるだけ(3.6)。倒れてくる木にプレイヤーが当たる判定はコード上に見当たらない(木が倒れてもプレイヤーはダメージを受けない)。

### 3.6 しびれ(鳥のフン)

- フンに当たると 1.4 秒(`STUN_TIME`)しびれる。移動もオノもできず、かくれることもできない。
- しびれている間、振っていたオノの動作は中断される。
- 無敵時間中でもフンには当たる(フンの判定は無敵を見ていない)。
- 面クリアやミスの時点で、しびれは解除される(ミスのとき `player.stun = 0`、面開始・復活時も `resetActors()` で 0)。

## 4. ステージ進行とクリア条件

### 4.1 面の開始(`setupStage()`)

- 木を3本(`TREES_PER_STAGE`)立てる。画面の x = 120 〜 600 の範囲を3つの区画(幅 160 px)に分け、各区画の中央に ±25 px の範囲でランダムにずらして1本ずつ植える。各木の HP は 8。
  - 木のおおよその位置は x ≈ 200 / 360 / 520(それぞれ ±25)。
- 敵・枝・鳥・フン・アイテム(安全ピン・ビール缶)をすべて消す。プレイヤーを x = 50、右向きに戻し、2 秒間の無敵にする。
- 敵の最初の出現までの時間は 2.5 秒、鳥の最初の出現までの時間は 5 秒。

### 4.2 面クリア条件

- 3本すべての木が「倒れ終わった」状態になること。つまり、立っている木がなく、かつすべての木が倒れ切って(角度が 90°に達して)いるか、消えていること。
- 木を倒し始めた時点ではクリアにならず、最後の木が倒れ切った時点でクリアになる。

### 4.3 面クリア時の流れ

1. `clear` 状態に入り、ボーナスとして `1000 × 現在の面数` 点が入る(2面なら 2000 点)。
2. 2.6 秒間、「STAGE n クリア!」と「ボーナス ○○ 点」が表示される。この間は木の更新だけが行われ、プレイヤー・敵・鳥などは更新されない(動きは止まる)。ただし見た目の演出として、モク太は拳を突き上げ、モヒカンを揺らし、「OI!」の吹き出しを出す(7.4 参照)。
3. 面数が 1 増え、次の面が始まる。

- 得点・残機・集めた安全ピンの数は次の面に持ち越される。残機は安全ピンを集めると増える(5.8 参照)。
- **最終面・エンディングの設定はない**。クリアすると面数が増え続ける。上限の定義はコードに見当たらない(要確認: 仕様として意図した無限進行かどうか)。

### 4.4 面数による難易度の変化

`stage` は面数(1 始まり)。

| 項目 | 式 | 1面 | 3面 | 5面 | 上限 |
| --- | --- | --- | --- | --- | --- |
| 同時に出る敵の最大数 | `min(4, 2 + floor(stage/2))` | 2 | 3 | 4 | 4 |
| イノシシが出る確率 | `min(0.5, 0.2 + stage × 0.05)` | 0.25 | 0.35 | 0.45 | 0.5 |
| 敵の出現間隔の基準(秒) | `max(1.6, 4.2 − stage × 0.3)` | 3.9 | 3.3 | 2.7 | 1.6 |
| ヘビの速さ(px/秒) | `45 + stage × 8` | 53 | 69 | 85 | なし |
| イノシシの速さ(px/秒) | `190 + stage × 15` | 205 | 235 | 265 | なし |
| 枝が落ちる確率(1回オノを入れるごと) | `min(0.5, 0.18 + stage × 0.04)` | 0.22 | 0.30 | 0.38 | 0.5 |
| 鳥の出現間隔の基準(秒) | `max(4, 9 − stage × 0.6)` | 8.4 | 7.2 | 6.0 | 4 |
| 鳥の速さ(px/秒) | `100 + stage × 8` | 108 | 124 | 140 | なし |
| 鳥が落とすフンの数 | 1(3面以上は 2) | 1 | 2 | 2 | 2 |

- 敵・鳥の実際の出現間隔は、基準値に 0.7 〜 1.3 倍のランダムをかけた値。
- ヘビ・イノシシ・鳥の速さには上限がないため、面が進むほど際限なく速くなる(要確認: 意図した仕様か)。

## 5. 敵キャラクターの動作

敵はすべて地面の上(y = 400)を横方向にだけ動く。ジャンプや縦の動きはない。画面の左右どちらかの端から等確率(50%)で出現する。

### 5.1 出現(`spawnEnemy()`)

- 敵の出現タイマーが 0 になるたびに出現を試みる。すでにいる(倒されていない)敵の数が同時最大数(4.4 参照)以上のときは、その回は出現しない。
- 出現するたびに、イノシシ(確率は 4.4 参照)かヘビ(残り)かが決まる。

### 5.2 ヘビ

| 項目 | 内容 |
| --- | --- |
| 出現位置 | x = -20(左端の外)または x = 660(右端の外) |
| 速さ | `45 + stage × 8` px/秒(ゆっくり) |
| 当たり判定の半幅 | 16 px(プレイヤーとの接触判定では 4 px 引いた 12 px を使う) |
| 向きの変更 | 画面内(x が 40 〜 600 の間)で、2 〜 5 秒ごとに向きを反転する。反転は1匹につき最大2回 |
| 予告 | なし |
| 倒したときの得点 | 100 点(オノ)/ 300 点(倒れた木の下敷き) |

### 5.3 イノシシ

| 項目 | 内容 |
| --- | --- |
| 出現位置 | x = -30(左端の外)または x = 670(右端の外) |
| 予告 | 出現してから 1.0 秒間は動かず、出てくる側の画面端に赤い「!」が点滅する(左から出るときは x = 16、右からのときは x = 624)。この間は敵本体は描かれず、当たり判定もなく、オノでも倒せない |
| 動き | 予告後、出てきた方向へ一定の速さで突進する。向きは変えない |
| 速さ | `190 + stage × 15` px/秒 |
| 当たり判定の半幅 | 20 px(接触判定では 4 px 引いた 16 px を使う) |
| 倒したときの得点 | 200 点(オノ)/ 300 点(倒れた木の下敷き) |
| 見た目 | 頭に小さな赤いモヒカン。突進の勢いで後ろになびき、走りに合わせて揺れる。見た目だけで、速さ・予告・当たり判定は変わらない |

### 5.4 敵の共通動作

- 敵とプレイヤーの接触判定は左右方向の距離だけ(`|敵x − プレイヤーx| < 敵の半幅 − 4 + 10`)。
- 接触してもミスにならない条件: プレイヤーが木の陰にかくれている、または無敵時間中。
- 敵は木やほかの敵とは干渉しない。
- 画面外(x < -60 または x > 700)に出た敵は消える。
- 倒された敵は、その場で消える(倒れるアニメーションはなく、パーティクルが出る)。

### 5.5 落ちてくる枝(`spawnBranch()`)

敵ではないが危険物として記載する。

- **発生条件**: 木にオノが当たったとき、確率(4.4 参照)で発生する。ただし、その一撃で木の HP が 0 になる(木が倒れる)ときは発生しない。
- **落ちる位置**: x は「木の位置とプレイヤーの位置の中間」を中心に ±35 px の範囲でランダム。高さ y = 170(葉の中)から落ちる。
- **予告**: 発生してから 0.65 秒間は落ちず、枝が葉の中で揺れ、地面に影が広がる。
- **落下**: 重力加速度 900 px/秒²で落ち、回転する。
- **当たり判定**: 高さが y = 344 〜 390 の間にあり、プレイヤーの無敵でないときに、左右の距離が 22 px 未満(枝の半幅 12 + プレイヤーの半幅 10)ならミス。**かくれていても当たる**。
- 地面(y ≥ 394)に着くと消える。

### 5.6 鳥とフン(`spawnBird()` / `updateBirds()`)

- **出現**: 左右どちらかの端の外(x = -20 / 660)から出現。高さは y = 50 〜 100 のランダム。左右に一定の速さで飛び、画面外(x < -40 または x > 680)に出ると消える。
- **フンを落とす条件**: フンの残り数があり、前回から 0.8 秒以上たっていて、鳥とプレイヤーの横の距離が 60 px 未満のとき、毎フレーム「`dt × 3`」の確率で落とす(1秒あたり平均3回分の判定)。
- **フン**: 初速 60 px/秒で、重力加速度 300 px/秒²で落ちる。
- **当たり判定**: 高さが y = 344 〜 390 の間、左右の距離が 16 px 未満(フンの半幅 6 + プレイヤーの半幅 10)で、かくれておらず、すでにしびれてもいないときに当たる。当たると 1.4 秒しびれる。
- 地面(y ≥ 398)に着くと消える。
- 鳥自体はオノで倒せない(鳥を攻撃する処理はない)。

### 5.7 倒れる木による下敷き

- 倒れ始めた木は、角度が 0.9 ラジアンを超えた時点で1回だけ、倒れる側にいる敵を判定する。
- 木の根元から倒れる方向に 10 px より遠く 290 px より近い位置(`GROUND − CANOPY_Y + 40` = 290)にいる敵が、まとめて倒される(各 300 点)。
- 出現予告中のイノシシと、すでに倒した敵は対象外。かくれ状態などは見ない。

### 5.8 アイテム(`spawnItem()` / `updateItems()`)

危険物とは別に、拾うと得をするアイテムが2種類ある。当たってもミスやしびれにはならない。

#### 安全ピン

| 項目 | 内容 |
| --- | --- |
| 出現①(木を切る) | オノを木に当てるたび 6%(`PIN_CHOP_CHANCE`)の確率で、木の葉っぱの高さ(y = 170)から、木の x ±40 px の位置に落ちてくる。木を倒す一撃でも出る |
| 出現②(敵を倒す) | イノシシを倒すと 100%(`PIN_BOAR_CHANCE`)、ヘビを倒すと 20%(`PIN_SNAKE_CHANCE`)で、その場で上に小さく跳ねて落ちる。オノでも下敷きでも同じ |
| 落ち方 | 落ちる速さは最大 170 px/秒で、ゆらゆら左右に揺れながら落ちる。0.8 秒ごとにキラッと光る(影の予告がある危険な枝と見分けやすくするため) |
| 同時に出る数 | 最大 2 本(`PIN_MAX`)。それ以上は出ない |
| 集める数 | 5 本(`PINS_FOR_LIFE`)集めると残機が 1 増え、数は 0 に戻る。「1UP!」の表示と `oneup` の音が出る |
| 残機の上限 | 5(`LIFE_CAP`)。上限のときに 5 本集めると、残機の代わりに 1000 点(`SCORE_PIN_FULL`)。数は 0 に戻る |
| 数の引き継ぎ | 面をまたいで持ち越し、ミスしても減らない。新しいゲームを始めると 0 に戻る |

#### ビール缶

| 項目 | 内容 |
| --- | --- |
| 出現 | 木が倒れ始めたとき、35%(`CAN_CHANCE`)の確率で、根元から飛び出す |
| 例外 | その面の最後の木からは出ない(倒れ切るとすぐ面クリアになり、拾えないため) |
| 飛び方 | 上へ跳ね上がり、倒れる方向と反対側(プレイヤーがいる側)へ弧を描いて飛び、木から約 110 px 離れた地面に落ちる。プレイヤーの後ろに落ちるので、少し歩いて拾いに行く |
| 得点 | 500 点(`SCORE_CAN`)。「+500」の表示と、「プシュッ」と「チーン」の音(`can`) |
| 同時に出る数 | 最大 1 個(`CAN_MAX`) |
| 見た目 | レトロゲーム風のドット絵(8×12 マス、1 マス 2 px)。銀のフタ、金色の胴、白い印の入った赤い帯。架空のデザインで、実在の銘柄は使わない |

#### 共通

- **拾い方**: アイテムが頭の高さより下(y > 340)にあり、プレイヤーと左右の距離が 18 px 未満(半幅 8 + プレイヤーの半幅 10)なら拾う。
  - 跳ね上がっている途中(上向きに動いている間)は拾えない。落ちてくる途中と地面にあるときに拾える。
  - 木の陰にかくれている間は拾えない。しびれている間は拾える。
- **消えるまで**: 地面に落ちてから 8 秒(`ITEM_LIFE`)で消える。最後の 2 秒は点滅する。
- **ミス・面の開始**: 画面上のアイテムはすべて消える(敵・枝などと同じ)。
- アイテムは画面の左右の端(x = 20 〜 620)からはみ出さない。
- 目安(1 面あたり): 安全ピンは 1.5〜3 本ほど出る(敵をどれだけ倒すかで変わる)。缶は平均 0.7 個(2 本 × 35%)。

## 6. 得点・残機・ゲームオーバー条件

### 6.1 得点

| 内容 | 得点 | 備考 |
| --- | --- | --- |
| 木にオノを1回当てる | 10 | 空振りは 0 点。得点の表示(ポップアップ)は出ない |
| 木を倒す(HP が 0 になる一撃) | 500 | 一撃分の 10 点に加えて入る |
| ヘビをオノで倒す | 100 | |
| イノシシをオノで倒す | 200 | |
| 倒れる木の下敷きで敵を倒す | 300 | ヘビ・イノシシ共通 |
| 面クリアボーナス | 1000 × 面数 | 画面中央のテキストに表示され、得点ポップアップは出ない |
| ビール缶を拾う | 500 | 5.8 参照 |
| 残機が上限(5)のときに安全ピンを 5 本集める | 1000 | 上限でなければ得点の代わりに残機 +1 |

- 1面を最短(木に8回 + 倒す)でクリアすると、木1本あたり `10 × 8 + 500 = 580` 点、3本で 1740 点、ボーナス 1000 点で合計 2740 点になる(敵を倒さない場合)。
- 得点が出る場面では、得点の数字が上へ浮かびながら 0.9 秒で消える(木の一撃・面クリアを除く)。

### 6.2 ハイスコア

- 現在のスコアがハイスコアを超えた瞬間にハイスコアを更新し、`localStorage` のキー `kikoriMokuta.highScore` に保存する(ゲーム中に随時保存)。
- ハイスコアを更新した場合、そのゲームではゲームオーバー画面に「ハイスコア更新!」が表示される。
- 保存済みのハイスコアが 0(初回など)のときは、最初に得点した時点でハイスコア更新扱いになる(コード上の挙動。意図した仕様かどうかは要確認)。
- `localStorage` が使えない環境でもゲーム自体は動く(例外を握りつぶして続行)。その場合の保存・復元はされない。

### 6.3 残機

- 初期の残機は 3(`MAX_LIVES`)。
- ミスのたびに 1 減る。減るのは、やられ演出(2 秒)が終わった時点。
- 安全ピンを 5 本集めると 1 増える。上限は 5(`LIFE_CAP`)(5.8 参照)。

### 6.4 ミス後の流れ

1. `dying` 状態になり、2 秒間のやられ演出(倒れた姿と浮かぶ魂)。この間、敵・枝・鳥・木の更新は止まる。
2. 演出後に残機を 1 減らす。
3. 残機が 1 以上なら、敵・枝・鳥・フン・アイテムをすべて消して(出現タイマーも初期値に戻る)、2 秒の無敵をつけてその場で `playing` に戻る。集めた安全ピンの数は減らない。
   - 木の状態(残りの HP など)と倒した木はそのまま。プレイヤーの位置も戻らない(やられた場所から再開)。
   - 倒れている最中だった木は、その途中から再開する。
4. 残機が 0 なら `gameover` になる。

### 6.5 ゲームオーバー

- 条件: ミスの演出後に残機が 0 になること(時間切れなどの条件はない)。
- 画面に「ゲームオーバー」とスコア、(更新時は)「ハイスコア更新!」が表示される。
- スペース等・クリック・タッチで、スコア 0・残機 3・安全ピン 0・1面から新しく始める。

## 7. 画面表示と演出

### 7.1 HUD(画面上部の帯、高さ 30 px)

| 位置 | 表示 |
| --- | --- |
| 左 | `SCORE` 現在の得点 |
| 左寄り(x = 140 付近) | 安全ピンのアイコンと「集めた数/5」。拾った直後の 0.4 秒は数字が黄色く光る |
| 中央やや左 | `HI` ハイスコア |
| 中央やや右 | `STAGE` 現在の面数 |
| 右寄り | `木 n`(立っている木の残り本数) |
| 右端 | 残機の数だけ赤いモヒカンの頭のアイコン。残機が 4 以上のときは、はみ出さないようアイコン 1 つと「×n」で表す |

### 7.2 画面中央のメッセージ

| 状態 | タイトル | サブ | ヒント(点滅) |
| --- | --- | --- | --- |
| `ready` | きこりのパンク | ヘビやイノシシをよけて、木を3本切り倒そう | スペース / クリック でスタート |
| `paused` | 一時停止 | (なし) | P または スペース で再開 |
| `clear` | STAGE n クリア! | ボーナス ○○ 点 | (なし) |
| `gameover` | ゲームオーバー | スコア ○○(更新時は「ハイスコア更新!」を追記) | スペース / クリック でもう一度 |

- ヒントは 0.5 秒ごとに点滅する。
- `ready` のサブ文言の「3本」は固定の文字列で、`TREES_PER_STAGE` の値とは連動していない。
- `dying` 中と `playing` 中には中央のメッセージは出ない。

### 7.3 背景

- 空(青のグラデーション)、遠くの山、奥の森のシルエット(三角形の並び)、地面(土と草、小さな点の模様)。静止画で、スクロールや時間による変化はない。

### 7.4 キャラクターなどの描画

- **モク太**: パンクファッションの木こり。向きに合わせて左右反転する。歩くと足が動き、オノを振ると前に振り下ろす。
  - **頭**: 横を剃り上げた頭に、大きな赤いモヒカン。小さな画面でも目立つよう、明るい赤に濃い赤の縁取りとつやのハイライトを付け、頭より高く突き出させる。担いだオノの刃に隠れないよう、オノより手前に描く。
  - **ひげ**: 茶色のひげ。モク太の個性として残す。
  - **鋲ジャン**: 黒いレザージャケット。前の合わせ・背中側・肩に銀の鋲が並び、正面だけでなく背中側にも鋲が見える。すそのベルトに黄色いステッチ。
  - **ブーツ**: 膝下まである 20 ホール相当の黒い編み上げブーツ。前側にハトメ(片側 10 個)とジグザグのひも、靴底のまわりとかかとの縫い目に黄色いステッチ、かかとに黄色いプルタブ。奥の足は少し暗い黒にして前後をわかりやすくする。
  - **左右反転**: 文字や左右で意味の変わる模様は入れず、鋲を前と背中の両方に置いているので、反転しても不自然にならない。
  - **モヒカンの揺れ**: 歩くと後ろになびき、足の動きに合わせて揺れる。オノを振ると勢いで大きく後ろへなびく。止まると、ばねのように元の形に戻る。面クリア中はリズムに乗るように左右に揺れる。
  - **鋲のきらめき**: 0.9 秒ごとに鋲が 1 つ、0.2 秒だけ十字にキラッと光る。どの鋲が光るかは時刻から決まる(乱数は使わない)。
  - **キメポーズ**: 木を倒すと 0.8 秒(`POSE_TIME`)、背中側の腕で拳を突き上げる。最初の 0.1 秒で腕を振り上げる。歩いている間も出るが、オノを振っている間としびれている間は出ない。
  - 見た目だけの変更で、操作・当たり判定(半幅 10 px)・得点・難易度・ルールは変わらない。
- **無敵時間中**: モク太が点滅する(プレイ中のみ)。
- **しびれ中**: モヒカンのさらに上(地面から約 80 px の高さ)で黄色い星が3つ回る。モヒカンとは重ならない。モヒカンは後ろへぺったりへたり(つやも消える)、しびれが治ると元に戻る。
- **面クリア中**: 拳を突き上げたキメポーズのまま、頭の前上に「OI!」の吹き出しが出て、少し上下にふわふわ動く。吹き出しの文字は鏡文字にならないよう、左右反転せずに描く。画面の端ではみ出さない位置に寄せる。面クリアの時点でしびれていても、星やへたりは出さない。
- **やられ**: 横たわった姿(黒い鋲ジャン、黄色いステッチ入りの黒いブーツ、横に倒れた赤いモヒカン)と、浮かんでいく白い魂。
- **木**: 幹と葉で描く。切り込みが HP の減りに応じて深くなり、プレイヤーのいる側に見える。
  - 倒れるときは根元を支点に回転する。回転は徐々に加速する。
  - 倒れ切ると約 1.25 秒かけて薄くなって消え、切り株だけが残る。
- **敵**: ヘビはくねくね動き、イノシシは足と体が弾んで見える。どちらも進行方向を向く。イノシシの頭には小さな赤いモヒカン(5.3 参照)。
- **アイテム**: 安全ピンとビール缶はドット絵で描く(5.8 参照)。地面に落ちたビール缶には小さな影が付く。
- **1UP**: 安全ピンを集め切って残機が増えると、モク太の頭上に「1UP!」が浮かぶ。
- **鳥**: 羽ばたく。フンは白い丸。
- **パーティクル**: 木を切ったとき(木くず)、敵を倒したとき、木が倒れ切ったとき(葉)、枝が地面に着いたとき、フンが当たった/地面に着いたときに飛び散る。
- **画面の揺れ**: 木が倒れ始めたとき(揺れ 6)、倒れ切ったとき(8)、ミスのとき(10)に画面全体が短く揺れる(HUD は揺れない)。
- **木の揺れ**: オノが当たった木は 0.15 秒だけ左右に揺れる。

### 7.5 効果音(Web Audio API、`SOUNDS`)

| 名前 | 鳴るタイミング |
| --- | --- |
| `start` | ゲーム開始時、次の面の開始時 |
| `chop` | 木にオノが当たったとき |
| `whiff` | 空振り |
| `kill` | オノで敵を倒したとき |
| `crush` | 倒れる木で敵を下敷きにしたとき |
| `fall` | 木が倒れ始めたとき |
| `warn` | イノシシが出現して予告が始まったとき |
| `stun` | フンに当たってしびれたとき |
| `pin` | 安全ピンを拾ったとき(5 本目を除く) |
| `oneup` | 安全ピンを 5 本集めたとき(残機 +1、または上限時の 1000 点) |
| `can` | ビール缶を拾ったとき(ノイズの「プシュッ」とベルの「チーン」) |
| `miss` | ミスしたとき |
| `clear` | 面クリアしたとき。オリジナルのパンク風ジングル(約 1.6 秒) |
| `over` | ゲームオーバーになったとき。オリジナルのパンク風ジングル(約 1.9 秒) |

- **パンク風ジングル**: 歪ませたパワーコード(根音・5度・オクターブのノコギリ波)と、キック(サイン波の音程を急に下げた音)で作る。どちらもこのゲームのために作った短いフレーズで、既存の曲は使わない。
  - `clear`: E・E・G・A と勢いよく刻み、B・A・D と上がって、高い E で伸ばして終わる。
  - `over`: A・G・F・E と重たく下がり、最後の E がオクターブ下までだらんと沈む。

- 音の ON/OFF は M キーまたは「音: ON/OFF」ボタンで切り替え、`localStorage` のキー `kikoriMokuta.sound`(`'on'` / `'off'`)に保存する。
- ブラウザの自動再生制限のため、音声コンテキストは最初に音を鳴らすときに作られる。

### 7.6 メインループ

- `requestAnimationFrame` で毎フレーム `update(dt)` と `draw()` を呼ぶ。
- `dt` は最大 0.05 秒に制限される(フレーム落ちで大きく飛ばないようにするため)。

## 要確認事項のまとめ

コードだけでは仕様として意図したものか判断できない点です。

1. 最終面・エンディングがなく、面数が無限に進む点。
2. 面数が上がるとヘビ・イノシシ・鳥の速さに上限がなく、際限なく速くなる点。
3. プレイ中のクリック/タップではオノを振れない点(タッチ端末では「オノ」ボタンを使う)。
4. 保存済みハイスコアが 0 のとき、最初の得点で「ハイスコア更新!」が出る点。
5. `index.html` の操作説明に A/D/S/J/Enter/M が載っていない点(コードでは有効)。
6. `ready` 画面の「3本」の文言が固定で、`TREES_PER_STAGE` と連動していない点。
7. 倒れてくる木にプレイヤーが当たってもダメージがない点(コード上、判定が見当たらない)。
