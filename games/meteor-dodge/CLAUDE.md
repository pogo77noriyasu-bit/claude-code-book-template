# CLAUDE.md

このファイルは、流星よけプロジェクト(`games/meteor-dodge/`)専用のガイドです。リポジトリ全体の共通ルールはルートの `CLAUDE.md` を参照。

## 概要

ブラウザで遊ぶ避けゲー。画面下の自機を左右に動かし、上から降ってくる隕石をよけながら星を集めてスコアを稼ぐ。素の HTML + バニラ JavaScript で `<canvas>` に描画している。ビルド手順、パッケージマネージャ、テストはない。画面の文字とコードコメントはすべて日本語。

## 実行方法

`index.html` をブラウザで直接開くか、リポジトリのルートを静的配信して(例: `npx http-server -c-1 -p 8000`)`/games/meteor-dodge/` を開く。

## 操作

- ←→ / A D: 移動、マウス: カーソルに追従、タッチ: ドラッグで移動
- スペース / Enter / クリック / タップ: スタート・リトライ
- P: 一時停止、M: 効果音 ON/OFF(キャンバス下のボタンでも切り替え可)

## 構成

- `index.html` — レイアウトとスタイル、固定サイズの `<canvas id="game" width="480" height="640">`。CSS で画面に合わせて縮小表示する。
- `main.js` — ゲーム全体。上から順に、設定、状態、保存、効果音、初期化・状態遷移、入力、生成、更新、描画、ループ。

設計上の要点:

- **状態遷移**: 文字列 `state` で管理 — `'ready' | 'playing' | 'paused' | 'gameover'`。`launch()` が `ready`/`gameover` → `playing`、`togglePause()` が `playing`⇔`paused`。タブが非表示になると自動で `paused` になる。
- **時間**: breakout と違い、移動はデルタタイム(秒)ベース。`loop()` で `dt` を最大 0.05 秒に制限している。速度の定数は px/秒。
- **難易度**: `difficulty()` = 経過秒 / 20。隕石の落下速度・大きさ・横揺れ・出現間隔がこれで変わる。
- **落下物**: 隕石(`meteors`)とアイテム(`items`)。アイテムは `ITEM_TYPES` の重み付きランダムで、星(+50 点)・シールド(6 秒間無敵で隕石を壊せる)・ハート(ライフ +1、満タン時は星に置き換え)。
- **被弾**: ライフ 3。被弾すると `INVINCIBLE_TIME` 秒の無敵(点滅)。当たり判定は円同士で、見た目より少し小さめ。
- **得点**: 生存 1 秒ごとに 10 点、星 50 点、シールドで隕石を壊すと 20 点。

## 実装ルール

- スコアは `localStorage` に保存すること。キーは `meteorDodge.highScore`、効果音設定は `meteorDodge.sound`(`'on'`/`'off'`)。読み書きは必ず `loadStorage()` / `saveStorage()` を通す。
- 効果音は Web Audio API で合成し、ON/OFF を切り替えられるようにすること。鳴らすときは必ず `playSound(name)` を使う。
