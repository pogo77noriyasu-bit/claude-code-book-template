# CLAUDE.md

このファイルは、ポリス vs パンクスプロジェクト(`games/hoshimushi/`)専用のガイドです。リポジトリ全体の共通ルールはルートの `CLAUDE.md` を参照。

## 概要

ブラウザで遊ぶ固定画面シューティング「ポリス vs パンクス」。画面上に編隊を組んだ80年代ハードコアパンク風のモヒカンパンクスが、宙返りしながら突撃してくる。自機は POLICEマン(紺の制服・警官帽・サングラス)。素の HTML + バニラ JavaScript で `<canvas>` に描画している。ビルド手順、パッケージマネージャ、テストはない。画面の文字とコードコメントはすべて日本語。

80年代の固定画面シューティングの「仕組み」(編隊・突撃・捕獲ビーム・2機合体・ボーナスステージ・命中率表示)を参考にしたオリジナル作品。既存ゲームの名前・キャラクター・見た目は使わないこと。

タイトルは旧名「ほしむし艦隊」から「ポリス vs パンクス」に変えた(敵も虫からパンクスに変えた)。ディレクトリ名 `hoshimushi/` と保存キー `hoshimushi.*` は、リンクと保存済みのランキングを保つため旧名のまま残している。コード内の敵の種類名(`bee`・`moth`・`queen` など)も虫の名前のまま残している(画面に出る名前は下の表のとおり)。

## 実行方法

`index.html` をブラウザで直接開くか、リポジトリのルートを静的配信して(例: `npx http-server -c-1 -p 8000`)`/games/hoshimushi/` を開く。

## 操作

- ←→ / A D: 移動、スペース: 発射(押しっぱなしで連射)
- タッチ・マウス: 押している間、指の位置へ移動しながら連射
- スペース / Enter / タップ: スタート・リトライ
- タイトル画面・ゲームオーバー画面: ←→ / A D、または EASY / NORMAL / HARD のボタンをタップして難易度を選ぶ(ボタン以外をタップすると開始)
- P: 一時停止、M: 効果音 ON/OFF(キャンバス下のボタンでも切り替え可)

## 構成

- `index.html` — レイアウトとスタイル、固定サイズの `<canvas id="game" width="480" height="640">`。フォントは Google Fonts の Press Start 2P / DotGothic16。
- `main.js` — ゲーム全体。上から順に、設定(ドット絵・ルート定義を含む)、状態、保存、効果音、スプライト、便利関数、状態遷移、入力、敵の行動、撃墜・被弾、更新、描画、ループ。

設計上の要点:

- **状態遷移**: `state` = `'ready' | 'playing' | 'paused' | 'entry' | 'gameover'`(`'entry'` はランキングの名前入力)。プレイ中はさらに `game.phase` = `'intro' | 'enter' | 'battle' | 'clear' | 'result'` で進行する。
- **時間**: デルタタイム(秒)ベース。`loop()` で `dt` を最大 0.05 秒に制限。
- **敵の動き**: ルートは3次ベジェ曲線を `buildPath()` で点列にし、`followPath()` でたどる。敵の `state` は `'enter'`(入場)→`'home'`(定位置へ戻る)→`'formation'`(編隊)→`'dive'` / `'beamDive'` / `'beam'`(攻撃)。`'morph'` は3機編隊へ変身中。
- **キャラクター**: 敵の種類(コード名 → 画面の名前 / モヒカンの色)は `bee` → レッドパンク / 赤、`moth` → ブルーパンク / 青、`queen` → ボスパンク / 緑(1発当たると `queen2` で紫)、`firefly` → イエローパンク / 黄、`mantis` → チェーンパンク / 水色、`cicada` → スパイクパンク / 橙、`dragonfly` → ピンクパンク / ピンク、`propeller` → ウニ頭パンク / 紫。自機 `player` は POLICEマン、`captive` / `traitor` は制服が赤い色違い。どれも横 13 ドット、1 ドット 2px。当たり判定はドット絵の大きさと関係なく、固定の数値(`checkCollisions()` など)で決まる。
- **編隊**: 40機(女王4・ヒラリ16・ブンブン20)。定位置は `slotPos(row, col)`。入場中は左右に揺れ、全員そろうと伸び縮み(`breathK` で切り替え)。行 `-1` は敵にされた自機(traitor)用。
- **捕獲と合体**: 女王がビームで自機を捕まえると `captive = true` で女王の上に付く。突撃中の女王を倒すと `rescue` が降りてきてダブル(`player.dual`)になる。編隊中に倒すと traitor になる。捕まった自機を撃つと 1000 点で救出失敗。
- **3機編隊への変身**: 4面以降、`launchAttack()` がときどき編隊中のブンブン/ヒラリを `'morph'` 状態にする(同時に1組まで、`game.morphGroup`)。0.8 秒点滅したあと `finishMorph()` で元の1機を消し、`MORPHS` の種類(4〜6面ホタル・8〜10面カマキリ・12〜14面セミ、以降くり返し)の3機を突撃させる。この3機は編隊に戻らず画面外へ逃げる。3機とも倒すと `bonus` 点。
- **チャレンジステージ**: `stage % 4 === 3`(3, 7, 11 …)。8機×5組が `CH_PATTERNS` のルートを飛ぶだけで攻撃しない。主役の敵は回ごとに `CH_TYPES` の順(ブンブン→ヒラリ→ホタル→トンボ→カマキリ→プロペラ→セミ)で変わり、2組目には女王が混ざる。トンボとプロペラはチャレンジステージ専用で、プロペラは向きに関係なく回転して描く。撃墜数×100、全機撃墜で 10000 点。
- **ランキング**: 上位5位を `[{ name, score }]` で保存。ゲームオーバー時に5位より高ければ `state = 'entry'` になり、3文字の名前を入力する(←→で選ぶ・英字キーで直接・スペース/Enter で決定・BackSpace で戻る、タッチは左右で選ぶ・真ん中で決定)。誤操作防止のため、ゲームオーバーから 0.8 秒間とキーリピートは無視する。HI-SCORE はランキング1位の得点。
- **残機**: `game.lives` は画面外の残機数。0 の状態で失うとゲームオーバー。20000 点で 1UP、以降 70000 点ごと。開始時の数は難易度で決まる(EASY 4 = 合計5機、NORMAL / HARD 2 = 合計3機)。
- **難易度**: `DIFFICULTIES`(`easy` / `normal` / `hard`)に倍率をまとめ、`launch()` で `game.diff` に入れる(プレイ中は変わらない)。選べるのはタイトル画面とゲームオーバー画面だけで、選んでいる難易度は `difficulty`。NORMAL はすべて 1 倍で、元のバランスのまま。
  - `speed`: 敵の移動速度。`followPath()` と `'home'` の移動でまとめてかけるので、入場・突撃・チャレンジステージのすべてに効く(EASY 0.8 / HARD 1.15)。
  - `attackInterval`: 突撃の間隔(1.5 / 0.75)。`maxDivers`: 同時突撃数の上限に足す数(−1 / +1、結果は 1〜7)。
  - `fireChance` / `maxFire`: 突撃した敵が弾を持つ確率と最大数(EASY 0.6・最大1発 / HARD 1.3)。`fireRate`: 撃つ頻度(0.6 / 1.3)。`shotSpeed`: 敵の弾の速さ(0.85 / 1.1)。
  - 得点・1UP の条件・ビーム・自機の性能は難易度で変えない。
  - 難易度を増やすときは `DIFFICULTIES` と `DIFF_ORDER` に足す。ボタンは `diffBtnX()` で3つ並べる前提なので、並べ方も直すこと。
- **ランキング**: 難易度ごとに別に保存する(`rankings[難易度]`。`ranking` は選んでいる難易度のもの)。登録はプレイした難易度(`game.diffKey`)へ。HI-SCORE とランキング表は選んでいる難易度のもの。

## 実装ルール

- スコアは `localStorage` に保存すること。ランキングのキーは NORMAL が `hoshimushi.ranking`(JSON。旧版と同じキーなので今までの記録を引き継ぐ)、EASY が `hoshimushi.ranking.easy`、HARD が `hoshimushi.ranking.hard`(`rankingKey()` で作る)。選んだ難易度は `hoshimushi.difficulty`(`'easy'`/`'normal'`/`'hard'`)、効果音設定は `hoshimushi.sound`(`'on'`/`'off'`)。読み書きは必ず `loadStorage()` / `saveStorage()` を通す。旧版の `hoshimushi.highScore` は、NORMAL のランキングが未保存のときに引き継ぐためだけに読む。
- 効果音は Web Audio API で合成し、ON/OFF を切り替えられるようにすること。鳴らすときは必ず `playSound(name)` を使う。
- ドット絵は `main.js` 冒頭の文字列グリッド(`GRID_*`)で定義し、色違いは `SPRITE_DEFS` の `remap` で作る。背景が黒なので、黒(`k`)は目やサングラスなど色のある部分の内側だけに使う(革ジャンやブーツは灰色の `e`)。グリッドを変えたら、弾が当たった瞬間の白い点滅(`bee_hit`)と捕まった自機(`captive`)の `remap` も見直すこと。
